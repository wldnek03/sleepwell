# SleepWell — 2분 수면 백색소음기

아이를 2분 안에 재우는 걸 목표로 설계한 백색소음 PWA.
단순 루프 재생이 아니라 **2분 유도 시퀀스**가 핵심이다.

```
0~20초    Hook     울음을 덮을 만큼 크고 밝게 시작
20~120초  Descent  볼륨 ↓ + 저역통과 cutoff ↓ (소리가 멀어지고 뭉개짐) + 심박 감속
120초~    Hold     어둡고 일정한 상태로 무한 루프
```

"크게 시작해서 서서히 줄인다"는 Harvey Karp의 5S 중 shushing 기법에서 가져왔다.

## 왜 소리를 미리 "굽는가"

실시간 Web Audio로 만들면 iPhone에서 두 가지가 깨진다.

1. 화면을 잠그면 `AudioContext`가 중단된다 → 자는 도중에 소리가 끊긴다.
2. iOS는 `HTMLMediaElement.volume` 설정을 무시한다 → JS로 페이드를 못 한다.

그래서 `js/synth.js`가 볼륨·필터·리듬 변화를 **전부 적용한 WAV**를 기기에서 생성하고,
평범한 `<audio>`로 재생한다. `<audio>`는 잠금화면에서도 계속 돈다.

프리셋마다 트랙 3개를 굽는다.

| 트랙 | 길이 | 용도 |
|---|---|---|
| `induction` | 128초 | 유도 시퀀스, 1회 재생 |
| `hold` | 약 30초 | 이음새 없는 무한 루프 |
| `fadeout` | 12초 | 종료 타이머용 |

`hold`는 **기본 주기(심박 또는 쉬싱 주기)의 정수배**로 잘라서 등파워 크로스페이드를
걸기 때문에 이음새에서 리듬이 어긋나지 않는다.

## 프리셋

| | 소리 | 성격 |
|---|---|---|
| 🤫 | 쉬-쉬 | 리듬형 쉬싱. 이미 울고 있을 때 가장 강력 |
| 🫧 | 자궁 소리 | 저음 + 74→54bpm으로 느려지는 심장박동 |
| 💨 | 드라이기 | 모터 허밍. 생활소음을 통째로 덮음 |
| 🌧️ | 빗소리 | 같이 자는 어른에게 편함 |

## 쓰는 법

**https://wldnek03.github.io/sleepwell/** → 공유 → **홈 화면에 추가**

한 번 열어두면 서비스워커가 앱 셸을 캐시하므로 이후에는 **비행기 모드에서도** 뜬다.
오디오는 매번 기기에서 생성되니 네트워크가 아예 필요 없다.

### 배포

`main`에 푸시하면 GitHub Pages가 알아서 반영한다 (1~2분).

```bash
git add -A && git commit -m "..." && git push
```

### 로컬 개발

```bash
cd ~/sleepwell
python3 -m http.server 8787      # http://localhost:8787
```

> LAN의 `http://`는 보안 컨텍스트가 아니라 서비스워커가 등록되지 않는다(앱 자체는 정상 동작).
> 캐시 때문에 변경이 안 보이면 Pages 쪽에서 홈 화면 아이콘을 지웠다 다시 추가하거나,
> `sw.js`의 `CACHE` 버전 문자열을 올린다.

## 검증

```bash
node tools/test_synth.js [출력폴더]   # 레벨/클리핑/루프 이음새 검사 + WAV 덤프
python3 tools/make_icons.py           # 아이콘 재생성
```

`test_synth.js`는 브라우저 없이 `synth.js`를 돌려서 확인한다.

- NaN/클리핑 없음
- hook → mid → settle 레벨 단조 감소 (프리셋별 5.7~8.6dB 차이)
- 유도 끝 레벨 ≈ 유지 루프 레벨 (전환 지점에 단차 없음)
- 루프 머리/꼬리 레벨 유사, 이음새 샘플 점프 없음
- 밝기(ZCR)가 1.9~4.5배 감소 → "멀어지는" 효과가 실제로 걸림

## 기록

"잠들었어요"를 누르면 `{프리셋, 소요시간}`이 localStorage에 쌓인다.
기록 시트에서 프리셋별 중앙값을 비교할 수 있다. 각 소리를 3회 이상 쓰면
**우리 아이에게 뭐가 제일 빨리 먹히는지 숫자로** 나온다. 그 프리셋을 기본으로 쓰면 된다.

"잠들었어요"는 소리를 끄지 않는다. 갑자기 멈추면 깨기 때문.

## 안전

- AAP 권고 **50dB 이하** — 어른이 보통 목소리로 대화 가능한 정도
- 침대에서 **최소 2m**, 머리맡 금지
- **밤새 금지** — 잠든 뒤 30~60분이면 종료 타이머로 끌 것

앱 안의 "안전" 버튼에도 같은 내용이 들어 있다.

